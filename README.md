# 🍃 Card Interativo - Naruto Uzumaki

Um projeto web simples e interativo que exibe um card de perfil do personagem **Naruto Uzumaki**, desenvolvido com HTML5, CSS3 e JavaScript.

---

## 🚀 Funcionalidades

- **Layout Responsivo:** Design centralizado e limpo, focado na experiência do usuário.
- **Estilização Temática:** Cores inspiradas no personagem (Laranja/Preto).
- **Interatividade:** Botão para alternar a exibição dos jutsus e transformações principais usando JavaScript.
